Whenever I ask you to design a page (form, etc.), always refer to this: https://ui.shadcn.com/docs/components

- There are ready-made components by shadcn for almost everything. Commonly required for forms are:
-- Combobox, Input, Switch, Toggle
-- For Radio, use Questionnaire

Most of them will already be in the project. But it's always better to double check

- Also REMEMBER TO USE DRY PRINCIPLE. If a component exists, use that.
